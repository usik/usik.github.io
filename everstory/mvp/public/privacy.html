개인정보 처리방침

버전 2026-10-27 · EverStory MVP

EverStory는 AI 캐릭터 이야기 서비스입니다. 현재 연결 준비 중이며, 서버가 준비되지 않은 상태에서는 사전등록 완료 또는 AI 대화 저장으로 표시하지 않습니다. 아래 내용은 연결 후 제공되는 기능과 데이터 처리 방식을 설명합니다.

1. 운영자와 문의

운영: GitHub usik의 EverStory 프로젝트. 개인정보 열람·삭제·동의 철회 등 문의는 프로젝트 문의로 접수할 수 있습니다. 공개 이슈에는 이메일 주소·대화 내용 등 개인정보를 적지 마세요. 비공개 확인이 필요한 경우 운영자가 별도 확인 방법을 안내합니다.

2. 수집 항목과 목적

구분항목 / 목적보관
사전등록 (선택)이메일, 언어, 동의 버전, 등록 시각. 출시 및 초대 안내, 중복 등록 방지.등록일부터 최대 1년 또는 철회 시까지
로그인 / 이야기사이트별 계정 식별자, 선택한 캐릭터·언어, 입력과 AI 응답, 선택지, 이야기 요약·관계·장소 상태, 시각. 계정별 이야기 제공 및 복원.마지막 이용 후 최대 90일 또는 삭제 요청 시까지
사용량 제한계정 식별자, IP의 서버 키 기반 해시, 요청 횟수·시간. 남용 및 과금 폭주 방지.제한 만료 후 최대 1일

이메일 사전등록을 하지 않아도 캐릭터를 탐색할 수 있습니다. 이야기 저장은 로그인이 필요합니다. 이메일 사전등록은 이메일 소유권 인증이나 로그인 계정 생성이 아닙니다. 결제 정보, 실명, 연락처는 요구하지 않습니다. 대화에 실제 민감정보를 입력하지 마세요.

3. 외부 처리 서비스

로그인과 호스팅에는 ChatGPT Sites 및 Cloudflare가 사용됩니다. 로그인 제공자가 전달하는 계정 식별자와 표시 이름을 사용하고, 로그인 이메일은 별도로 이야기 DB에 저장하지 않습니다. 이야기 기록과 사전등록은 Supabase에 저장되며, AI 응답 생성은 Google Gemini API로 처리합니다. Gemini에는 캐릭터 설정, 최근 12턴, 이야기 요약·상태, 현재 입력이 전송됩니다. 사전등록 이메일과 로그인 식별자를 Gemini 프롬프트에 넣지 않습니다.

출시 전 확인 항목: Supabase 프로젝트 저장 국가·리전, Google API의 실제 사용 요금제 및 데이터 이용 조건, 각 처리자의 보관 정책을 운영자가 확인하고 이 페이지에 반영해야 합니다. 이 확인과 인증이 끝나기 전에는 AI 대화와 사전등록을 정식 운영 완료로 안내하지 않습니다. API 데이터의 학습 사용 여부에 대해 현재 확인되지 않은 보장을 하지 않습니다.

4. 이용자 권리와 삭제

대화창의 “↓ JSON”으로 저장된 전체 이야기를 내려받고, “기록 삭제 / Delete”로 로그인한 계정의 모든 캐릭터 기록과 요약·상태를 삭제할 수 있습니다. 이메일 사전등록 삭제·정정·철회는 운영자에게 요청하세요. 부정 삭제를 막기 위해 해당 이메일의 소유자임을 확인할 수 있습니다. 브라우저 설정에서도 언어·임시 입력·동의 표시를 삭제할 수 있습니다.

5. 보안과 브라우저 저장

API 키와 DB 서버 키는 서버 비밀값으로 관리합니다. 클라이언트는 DB에 직접 접근하지 않습니다. 서버에서 계정별 권한, 요청 출처, 입력 크기, 사용량 및 모델 출력 형식을 검증합니다. 언어 설정은 localStorage에, 전송 전 임시 입력과 현재 탭의 동의 표시는 sessionStorage에 저장합니다. 로그인 쿠키는 로그인 제공자가 관리합니다. 별도 광고·행동 추적 도구를 넣지 않습니다.

6. 연령과 AI 안내

이 MVP는 만 20세 이상을 대상으로 합니다. 모든 캐릭터는 성인인 가상의 인물입니다. AI 응답은 사실·전문 조언이 아니며 오류가 있을 수 있습니다. 공개된 대본을 실제 AI 응답으로 표시하지 않습니다. 요청 실패도 남용 방지를 위해 사용 시도로 집계합니다. 기본 한도는 계정당 분당 6회·하루 30회이며, IP 및 서비스 전체 한도에 따라 더 일찍 제한될 수 있습니다.

7. 변경

처리 항목·외부 서비스·보관 기간이 바뀌면 이 페이지의 버전과 내용을 갱신하고 필요한 경우 다시 동의를 받습니다.

Privacy summary (English)

Optional waitlist email is retained for up to one year. Signed-in story history, summaries, and state are stored in Supabase for up to 90 days since last use. Recent conversation and memory are sent to Google Gemini to generate fiction. API credentials stay server-side. You can export or delete all your stories in the story dialog. Language and temporary drafts use browser storage. The MVP is for adults aged 20+. Hosting and sign-in use ChatGPT Sites/Cloudflare. The project region and provider data terms must be confirmed before production activation. Contact the operator through the linked GitHub project; never include personal data in a public issue.
