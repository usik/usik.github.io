## 실제 공개 서비스 + 실제 Gemini

테스트 브라우저의 ChatGPT 로그인 상태를 EverStory에서 확인한 뒤, 공개 API와 실제 모델로 아래를 검증했다. API 키를 읽거나 다시 입력하지 않았다. 요청에는 테스트용 허구의 문장만 사용했다.

1. 한국어 첫 장면: 한국어 대사·해요체와 선택지 3개 생성.
2. 한국어 장면 뜻 보기: 영어 장면 번역과 선택지 번역 3개 생성.
3. 한국어 교정: `저는 무섭다 하지만 같이 가고 싶어요.` → `무섭지만 같이 가고 싶어요.`와 영어 설명. 교정 원문이 입력창에 남아 있고 자동 전송되지 않음을 확인.
4. 교정안 적용 후 전송: 한국어 다음 장면과 표정 변형 저장. 새로고침 후 해당 입력 복원.
5. 난이도를 Standard로 변경 후 새로고침: 설정 복원.
6. 영어 첫 장면: 영어 대사와 선택지 3개 생성.
7. 영어 장면 뜻 보기: 한국어 장면 번역과 선택지 번역 3개 생성.
8. 영어 교정: `I am scare but I wants to help you.` → `I'm scared, but I want to help you.`와 한국어 설명. 적용 후 별도로 보내기 동작 확인.
9. 추천 선택지 클릭: 영어 세 번째 장면 생성.

Supabase에서 한국어 2턴 / 영어 3턴, meaning 캐시 2건 / polish 캐시 2건을 확인했다. 이는 모델 호출과 저장을 검증하기 위한 소규모 샘플이며, 학습 효과나 모든 응답의 정확성을 검증한 결과는 아니다. 테스트 기록은 사용한 계정의 연습 기록에 남겼으며, 기존 일반 대화를 삭제하지 않았다.

초기 인증 복귀가 `/callback` 404에 도착했으나, 새 로그인 흐름에서 기존 ChatGPT 계정을 선택한 뒤 정상 복귀·로그인 상태를 확인했다. 인증 코드를 수동 교환하거나 별도 callback을 구현하지 않았다. 첫 실패의 원인은 확정하지 않았다.

## 브라우저 검증 범위와 한계

- PC: 실제 로그인 + 실제 AI 기반 흐름을 검증했다.
- 390px 모바일 레이아웃: 로컬 disposable fixture로 첫 장면·뜻·교정·적용·전송·새로고침 복원을 확인했다. document width 390px, dialog width 390px로 가로 넘침이 없었다. fixture는 배포 전에 삭제했고 아카이브에 포함되지 않았다.
- 실제 휴대전화 Safari/Chrome에서의 로그인·대화 E2E는 아직 수행하지 않았다. 모바일 fixture를 실제 휴대전화 또는 실제 AI 모바일 E2E로 표현하지 않는다.
- 모델 오류/지연/사용량 한도는 여전히 발생할 수 있다. 언어 난이도는 지침에 따른 조절이며 공인 등급이나 교육 효과를 보장하지 않는다.

## 후속 모바일 폭 점검과 수정

공개 사이트를 Chrome iframe에서 320×568, 390×844, 430×932로 열었다. 각 화면의 document width가 viewport width와 같고 언어 선택 폰트는 16px이었다. 첫 320px 화면에서 모달을 510px 스크롤하면 닫기 버튼의 top이 -494px로 바뀌어 화면 밖으로 사라지는 문제를 재현했다.

720px 이하에서 모달의 닫기 버튼을 overlay 기준 fixed로 변경하고 safe-area inset을 적용했다. 로컬 실제 화면 코드에서 320px 화면(scrollTop 510), 390px 화면(scrollTop 111), 갤러리를 확장한 430px 화면(scrollTop 305)에 닫기 버튼 top=12px, 크기 44px를 확인했다. 버튼을 클릭해 모달이 닫히는 동작도 확인했다. 높이만 줄인 320×360 화면에서는 scrollTop 718에서도 top=12px / bottom=56px로 화면 안에 남았다. 이는 가상 키보드 검증이 아니라 짧은 viewport 검사다.

이 검사는 iframe의 모바일 폭에서 수행한 Chrome 레이아웃 검사다. 실제 휴대전화나 iOS Safari가 아니다. 공개 사이트를 다른 출처의 로컬 wrapper에 넣으면 기존 로그인 세션이 전달되지 않아 로그인 전 화면으로 나타났다. 삽입 화면에서 인증을 강제하거나 브라우저 보호 설정을 변경하지 않았다. 실제 휴대전화에서의 로그인·가상 키보드·AI 전송·재방문 복원은 계속 미검증이다.
