# 녹스 언어 연습 MVP 구현 명세

작성일: 2026-10-28 (KST). 상태: 구현 준비 완료 / 기능 미구현 / 공개 배지 비활성.

## 목표와 범위

캐릭터의 다음 이야기가 궁금해서 외국어를 쓰는 경험을 검증한다. 첫 대상은 녹스(`noah`) 한 명이다. 한국어 안내 + 영어 연습, 영어 안내 + 한국어 연습의 두 조합을 지원한다. 한국어 일반 스토리 등 기존 모드는 유지한다. 음성, 발음 평가, 시험 대비, 학습 효과 보장, 전 캐릭터 확장은 이번 범위에 포함하지 않는다. 기존 만 20세 이상 기준을 유지한다.

## 코드에서 확인한 출발점

- `public/everstory.js`의 `current`가 UI 표시 언어, `/api/story`의 `language`, 기록 조회 키를 모두 결정한다. 이를 분리해야 한다.
- `lib/api.mjs`는 ko/ja/en/es를 허용하며 모델에 해당 언어로 응답하도록 지시한다. 난이도·번역·교정은 없다.
- 이야기 PK는 `(owner_id, character_id, language)`이고 버전·잠금·요청 ID로 중복 전송과 동시 갱신을 통제한다.
- `state.playerNotes`는 사용자 입력의 정확한 고유명사와 설정을 보존한다. 학습 설정을 모델이 만드는 state 안에 넣으면 `validateOutput` 및 finish 갱신 때 유실될 수 있다.
- 실제 백엔드는 Supabase Edge에 복사된 API를 실행한다. `lib/api.mjs`만 고쳐서는 운영에 반영되지 않는다.
- SSR 홈/캐릭터 소개와 정적 `experience.html`의 카드·모달이 별도다. 배지와 진입 경로를 양쪽에서 맞춰야 한다.

## 화면 흐름

1. 녹스 카드 → 일반 이야기 / 언어 연습 선택. 검증 전에는 운영 배지를 노출하지 않는다.
2. 연습 선택 → 안내 언어, 연습 언어, 쉬움/보통 확인. 첫 버전은 위의 두 조합만 허용하고 미지원 조합은 조용히 대체하지 않는다.
3. 로그인 이동에도 캐릭터와 유효한 연습 설정을 보존한다. URL 값은 서버에서 다시 검증하며 URL만으로 설정을 저장하지 않는다.
4. 대화: 대사와 선택지 3개는 연습 언어로 표시. 버튼·오류·뜻·교정 설명은 안내 언어로 표시한다.
5. 각 AI 턴 아래 `뜻 보기 / Show meaning`으로 해당 대사와 선택지 번역을 펼친다. 원문과 번역을 시각적으로 구분하고 `aria-expanded`와 연결 영역을 제공한다.
6. 입력창의 `표현 다듬기 / Polish my sentence` → 수정안·짧은 이유 → 사용자가 적용하거나 닫는다. 원문과 커서 위치를 보존하고 자동 전송하지 않는다.
7. 대화 중 난이도·안내 언어 변경은 다음 생성부터 적용한다. 연습 언어 변경은 별도 기록으로 전환됨을 설명하고 기존 기록은 남긴다.

## 설정과 기록 계약

서버가 소유하는 설정 예시: `{mode:'practice', targetLanguage:'ko', supportLanguage:'en', level:'easy', koreanRegister:'polite'}`. 일반 모드 기본값은 `mode:'story'`다.

- `uiLanguage`는 사이트 표시 언어, `targetLanguage`는 대사 언어, `supportLanguage`는 번역·교정 언어다. v1에서는 연습 중 UI를 supportLanguage에 맞추지만 서로 다른 개념으로 유지한다.
- 기존 DB의 `language`를 대사 언어로 유지한다. 안내 언어 변경은 기록을 바꾸지 않는다.
- 일반 이야기와 연습 기록을 분리하도록 story/turn에 mode 키를 추가한다. 기존 행은 모두 `story`로 보존하고 PK·FK·조회·RPC·내보내기·삭제를 함께 수정한다. 기존 경로가 mode를 생략하면 항상 `story`다.
- 학습 설정은 이야기의 별도 typed 컬럼으로 저장한다. 모델이 생성하는 narrative state와 분리하고, 사용자·캐릭터별 최근 연습 언어는 별도 서버 설정으로 저장해 재방문 시 복원한다. 브라우저 초안 키도 mode/targetLanguage를 포함한다.
- 각 턴은 생성 당시 level과 한국어 말투를 저장한다. 설정은 버전 확인과 잠금을 거쳐 원자적으로 갱신하고, 생성 중인 설정 변경은 거절한다. requestId 재사용은 mode/설정이 다르면 충돌로 처리한다.
- 한국어 연습 v1은 해요체 중심이다. 녹스의 성격을 보존하되 캐릭터 설정 자체를 한국어 예절 규칙으로 오해하지 않게 하고, 반말·존댓말 구분은 필요한 경우 영어 도움말로 설명한다. 사용자의 반말을 무조건 문법 오류로 교정하지 않는다.

## API와 생성 방식

`GET/POST /api/story`에 선택적 `mode`, 연습용 설정을 추가한다. 설정 변경용 `POST /api/practice-settings`를 추가하고 소유자·version을 검증한다. `lib/bridge.mjs`와 Edge bridge의 경로 허용 목록도 같이 갱신한다.

스토리 생성은 기존 모델·JSON 스키마·3개 선택지·표정 enum·기억을 유지한다. 연습 모드만 별도 지침을 추가한다. easy는 짧은 문장과 흔한 어휘, standard는 더 자연스러운 문장을 목표로 한다. 공인 CEFR 등급을 보증하지 않는다. 학습 설정은 서버 검증값만 시스템 지침에 넣고 사용자 입력과 모델 memory는 계속 비신뢰 데이터로 취급한다.

`POST /api/practice-help` 제안:

- meaning: 소유한 turn의 ID/버전과 supportLanguage만 받는다. 원문과 선택지는 서버에서 읽고 모델에 보낸다. 클라이언트가 임의 원문이나 다른 사람의 기록을 주입할 수 없게 한다.
- polish: 소유한 story 키, 현재 draft(최대 1000자), requestId를 받는다. 문맥은 최근 소량으로 제한하고 제안 문장·짧은 설명·변경 여부만 반환한다. 한국어로 쓴 초안의 목표 언어 표현도 도울 수 있지만 목표 언어 입력과 구분해서 안내한다.
- 의미 응답은 `{sceneMeaning, choiceMeanings:[...3]}`로 검증한다. 원문 대사·선택지는 변경하지 않는다. 교정 응답은 `{suggestion, explanation, changed}`로 검증한다.
- 도움 요청은 story version/summary/playerNotes/turn 수를 변경하지 않는다. 교정이 사용자 의도나 고유명사를 바꾸지 않는지 테스트한다.
- 의미 결과는 `(owner,character,mode,targetLanguage,turnVersion,supportLanguage,promptVersion)`에 캐시한다. 동일 요청은 재사용하고 중복 클릭·동시 요청에 단일 처리 잠금을 둔다. 교정은 별도 requestId 결과로 짧게 캐시하고 초안 원문은 영구 저장하지 않는다.

## 비용·실패·개인정보

- 뜻은 요청할 때만 생성한다. 모델 호출 전 사용자 공통 분당 6회/하루 30회 한도를 스토리+도움 전체에 적용하고, 기존 IP·전체 일일 모델 호출 상한도 공유한다. 캐시 hit는 모델 호출을 소모하지 않도록 구현한다. UI 한도 문구와 정책을 함께 수정한다.
- 뜻/교정 실패는 원문 대화·입력 초안을 보존한다. 자동 전송이나 무한 재시도 없이 재시도 버튼을 제공한다. 모델 오류 시 잠금은 해제하고 비용 사용 시도는 차감될 수 있음을 설명한다.
- 도움말도 외부 AI 처리 대상이다. 기존 동의 범위와 개인정보 안내를 확인하고 번역·교정 목적을 추가한다. 운영 로그에는 대화·초안·번역 본문을 남기지 않는다.
- 새 테이블은 RLS, 서버 전용 권한, 소유자 조건을 유지한다. 캐시·최근 설정은 내보내기/전체 삭제와 연동하고 기록 90일 보관 정책을 넘기지 않는다. 새 개인정보 보관이 필요하면 먼저 정책을 갱신한다.

## 출시 순서와 완료 조건

1. 저장 키/하위 호환과 설정 분리 → 제한된 개발 환경에서 양방향 시작·복원 확인.
2. 언어별 프롬프트와 쉬움/보통 → 고정 입력 세트로 실제 Gemini 응답의 언어·길이·캐릭터성·3개 선택지·한국어 해요체 검토.
3. 뜻 보기 → 캐시·소유권·실패 복구 확인.
4. 표현 교정 → 적용/취소·입력 보존·자동 전송 없음 확인.
5. PC 및 모바일에서 로그인 복귀, 두 조합 각각 첫 장면→선택지→자유 입력→뜻→교정→새로고침 복원 E2E. 인증이 막히면 미검증으로 보고한다.
6. 기존 일반 모드 회귀, 다른 사용자 접근 차단, stale version·idempotency·동시 설정 변경, 전체 삭제/내보내기, 요청/토큰 상한 테스트.
7. 녹스만 기능 활성화 후 실제 공개 배포. 두 조합이 통과했을 때만 `영어·한국어 연습 / English · Korean practice` 배지를 SSR 홈·상세·채팅 카드에 표시한다. 기능 비활성 시 기존 모드는 계속 동작한다.

배포 순서는 하위 호환 DB 확장 → 기능 비활성 Edge → 프런트 → 실제 검증 → 기능 활성화·배지 공개다. 롤백은 연습 진입과 도움 API를 비활성화하고 이미 저장된 기록은 보존한다. 파괴적 스키마 되돌리기는 하지 않는다.

## 출시 후 측정

유입 source별 연습 시작, 첫 자유 입력, 5턴 도달, 뜻/교정 사용을 집계한다. 메시지 본문은 분석 이벤트에 포함하지 않는다. 현재 일별 익명 hash 분석으로는 다음 날 동일인의 재방문을 정확하게 측정할 수 없다. 익명 식별자를 늘리지 말고, 재방문이 필요하면 인증된 소유자 기반 서버 집계의 목적·보관 기간·정책을 별도로 설계한 뒤 적용한다. 소규모 방문 초기에는 통계적 우위를 단정하지 않고 사용자 피드백을 함께 본다.

- 화면: `public/everstory.js`, `public/experience.html`, 기존 CSS, SSR `app/page.tsx`, `app/characters/[id]/page.tsx`.

- 검증: `tests/api.test.mjs`, `tests/bridge.test.mjs`, 신규 practice 테스트 및 기존 공개 페이지 검사.
